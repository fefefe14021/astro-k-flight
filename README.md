# astro-k-flight

2D Unity-проект (Asteroid Shooter).

## Открытие в Unity Hub

1. Установите **Unity 6000.6.6f1** (или новее той же ветки 6000.x) через Unity Hub. Клонируйте репозиторий целиком — нужны папки `Packages` и `ProjectSettings`, не только `Assets`. Для 6000.6 нужен **Input System 1.20.1** (уже в `Packages/manifest.json`); старые версии пакета дают сотни ошибок `CS0619`.
2. **Projects → Add → Add project from disk**.
3. Укажите корень этого репозитория (папка, где лежат `Assets`, `ProjectSettings`, `Packages`).
4. Откройте проект — при первом запуске Unity скачает пакеты и создаст локальную папку `Library` (она в git не хранится).

Стартовая сцена в Build Settings: `Assets/Scenes/Bootstrap.unity`.

### Если Linux пишет «приложение не отвечает»

На **первом** открытии редактор может 2–5 минут висеть на шаге `InitializeOnLoadMethod` — это нормально (импорт пакетов и компиляция). Нажмите **«Подождать»**, не «Принудительно завершить».

Если зависание повторяется каждый раз:

1. Закройте Unity.
2. Удалите в папке проекта каталоги `Library`, `Logs`, `Temp` (они пересоздадутся).
3. Откройте проект снова и снова выберите **«Подождать»** до появления окна редактора.
